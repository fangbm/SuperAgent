# 🐞・问题反馈-bug-reports · Bug Reports

请先搜索论坛，确认不是重复主题；使用一个主题描述一个问题。标题写清现象和平台。尽量提供复现步骤、预期/实际结果、游戏版本（如可见）、Windows 或 macOS/芯片信息，以及不含个人隐私的截图或短视频。描述不确定的细节即可，不必猜原因。

Search the forum first and use one post per issue. Make the title describe the symptom and platform. Include reproduction steps, expected/actual result, game version (if visible), Windows or macOS/chip information, and a privacy-safe screenshot or short clip if useful. It is fine to mark details as unknown; do not guess at the cause.

请勿公开上传存档、密码、令牌或含个人资料的截图。需要工作人员私下协助时，请在 🔒・私密求助-private-help 留言或联系在线版主；目前由工作人员人工处理。

Do not publicly upload save files, passwords, tokens, or screenshots containing personal data. For private staff help, use 🔒・私密求助-private-help or contact an available moderator; requests are handled manually for now.

```text
[标题 / Title]

问题 / What happened:

预期结果 / Expected result:
实际结果 / Actual result:
频率 / Frequency:
附件 / Privacy-safe evidence (optional):
```
