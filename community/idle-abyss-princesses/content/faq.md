# 常见问题：游戏基础 · FAQ: Game Basics

**这是什么游戏？ / What is the game?**
《深渊放置姬》（Idle Abyss Princesses）是 Peter 开发、Mirako 发行的桌面放置刷宝 RPG。Steam 商店页：<https://store.steampowered.com/app/5335850/>。

Idle Abyss Princesses is a desktop idle loot RPG developed by Peter and published by Mirako. See the <https://store.steampowered.com/app/5335850/> Steam store page.

**支持哪些系统和语言？ / Platforms and languages?**
Steam 列出的平台为 Windows 和 Apple Silicon Mac；支持简体中文、繁体中文、英语、日语、韩语。请查看商店页的当前系统需求。

The listed platforms are Windows and Apple Silicon Mac. Supported languages are Simplified Chinese, Traditional Chinese, English, Japanese, and Korean. Check Steam for current system requirements.

**离线和放置如何运作？ / Offline and idle play?**
单人内容可离线游玩。战斗在游戏最小化时继续；游戏关闭或电脑休眠时没有战斗奖励。营地派遣按现实时间运行。

Single-player content can be played offline. Battles continue while minimized, but give no battle rewards while the game is closed or the computer sleeps. Camp dispatches use real time.

**怎么联机？ / How does co-op work?**
Everlasting Night Court 可单人挑战，也支持 2–4 名玩家总计（包括你）；联机需要网络。去 🤝・组队招募-lfg 找队友。

Everlasting Night Court can be played solo or by 2–4 players total, including you. Co-op requires an internet connection. Find a party in 🤝・组队招募-lfg.
