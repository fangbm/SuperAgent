# ADR 0021：工作项结构化报告

2026-11-05。PR A，不改变 M0、ReportV2、M3 提取 Schema 或模型调用。

Reporting 提供平台无关 WorkReportBuilder 与内部 BugReportV1/SuggestionReportV1，从 Domain 可见的工作项、active 的原始提取记录及其证据生成确定性数据和 Markdown。不同反馈保留自身提取字段、来源及置信度，不拼凑跨版本复现或猜测根因、影响范围、验收标准。玩家原文、AI 提取和开发者状态确认分别展示；开发者确认工作项不等于逐项确认所有模型字段。

只包含同项目、当前可见且非删除的 primary 来源；context 只作引用，附件必须位于该条 primary 原文，不按时间、文件名或其他上下文猜测关联。PR A 只输出附件元信息，不宣称下载、上传或视觉分析。没有可见 primary 时暂停该工作项同步，不使主程序循环因预期缺失证据而退出。

GitHubSyncManager 只替换原有初始 Issue/机器人专用评论的报告渲染。marker、外部操作账本、未知结果对账、人工正文/评论保护保持原机制；不 PATCH Issue 正文。玩家/模型文本转义为数据，固定开发工具提示不授予执行权限。报告有条目/字段/正文长度上限，缺失内容明示未确认，内容哈希与构建时间无关。

PR B 将提供附件捕获/私有本地存储/授权读取；PR C 按用户要求直接上传 GitHub Issue 附件，不使用独立证据仓库。真实平台支持与受控模拟分别验收。
