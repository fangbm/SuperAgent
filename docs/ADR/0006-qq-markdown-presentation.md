# ADR 0006：QQ 发送模板与封存数据分离

日期：2026-11-03。状态：已采用；新样式已通过本地验证，未追加真实 QQ 发送。

旧消息存在标题重复、字段层级不明显、界面英文与 UTC 时间混杂的问题。用户指定根据官方 Markdown 文档重新设计模板，并需要可直接查看的 Markdown 源文件。

在 reporting 包中增加纯展示入口及 `templates/qq/*.md`，由 control-plane 的 QQ 查询和 plugin-host 的报告投递共用。只使用 QQ 官方列明的标题、加粗、列表、块引用、分隔线和段落。模板单次替换经过约束的字段，源内容不作为模板代码执行。所有状态机、身份、令牌、分页顺序与统计仍使用现有服务。

Host 私有 `bodyIncludesTitle` 选项说明正文已包含标题；平台适配器只处理该选项，不读取业务或模板文件。平台连接器仍仅依赖 SDK。旧投递选项不存在此字段时保留原行为，封存报告与已经发送的请求均不改写。报告明确格式拒绝时的纯文本保底继续存在；unknown 不触发重试或格式降级。

原文页在展示层进行字面 Markdown 转义；CommonMark 参考解析器作为开发依赖，独立检查原文内容、emoji 分页和非预期图片/链接/标签。它不进入平台插件或生产展示依赖，也不构成 QQ 客户端渲染证明。

兼容性：不修改 M0 契约、SDK、默认配置、fixtures、冻结清单或数据库迁移。新增 reporting 到 plugin-host 的显式依赖和 TypeScript reference，templates 纳入私有包文件列表。展示渲染只应用于新请求，历史数据不迁移。
