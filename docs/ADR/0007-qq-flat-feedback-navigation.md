# ADR 0007：QQ 分类直接展示反馈内容

日期：2026-11-03。状态：已采用；本地验证范围见 M5 验收记录，尚未追加此导航版本的 QQ 客户端验收。

用户认为“半日报 → 列表 → 详情 → 原文”的按钮层数太多。新签发的栏目导航直接进入分类内容卡，合并摘要、当前状态和首条原文。报告到短原文从三次点击缩为一次；每张卡片展示一个成员，上一条、下一条按封存报告顺序切换，不再引入必经列表或详情页。

首条原文最多展示 800 个 Unicode 代码点，保留字面内容。长文通过“继续原文”从第 801 字接续到已有完整分页；短文有其他来源时直接提供“下一条原文”。独立原文页可返回当前反馈或同一份半日报。空栏目说明覆盖边界并提供返回入口。状态操作直接附在内容卡，仅由当前角色和状态允许的动作签发令牌，不增加处理菜单层。

所有导航绑定操作者、项目、报告 ID、修订与成员位置。返回半日报固定原修订，不跳到最新报告；工作项的当前状态与原文归档修订明确区分。原文仍使用 seal 对应的 evidence 锚点。新路线使用独立稳定令牌键名，避免复用旧栏目令牌的身份；旧 section/work/evidence 路线继续解析，已发请求和封存报告不迁移、不改写。

新增 feedback.md 和 reporting 展示函数；Core 与平台 SDK 的边界保持原样，不修改冻结 contracts、SDK、Schema、fixtures、默认配置或数据库迁移。QQ 发送器继续使用现有键盘接口、鉴权、被动回复上下文和 unknown 不重发规则。

离线预览改为调用真实 QQ 控制服务生成卡片及按钮标签，避免示意按钮和实现脱节。验证包含三项反馈顺序与返回、空栏目、Steam 原文直达、旧令牌兼容、800 字起始与后续完整分页、超过五十个来源原文、特殊字符/emoji/3500 字符边界、角色权限和 HTTP 被动回复。
