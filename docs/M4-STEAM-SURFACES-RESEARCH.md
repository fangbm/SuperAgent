# Steam AppID 5335850 — public surfaces and endpoint audit

Checked 2026-11-03. Scope was anonymous public reads only: no cookies, login, session values, auth bypass, or desktop interaction. Steam Community requests used an ordinary public User-Agent. The web research tool could not open several Steam Community/API URLs, so their status below comes from direct anonymous `Invoke-WebRequest` probes; that tool failure is not treated as a platform restriction.

## Native discussion endpoint evidence

The public topic page loads Steam’s current `forums.js` and `global.js`. The topic page calls `InitializeCommentThread("ForumTopic", "ForumTopic_{owner}_{forumGid}_{topicId}", …, "https://steamcommunity.com/comment/ForumTopic/", 40)`. Steam’s current public `global.js` constructs render paths as `base + "render/" + owner + "/" + feature + "/"`; page navigation uses `start = pageSize * page` and passes `feature2` (the topic ID), `totalcount`, and sort flags. The sample topic’s JS reports one reply, but the anonymous render request returned the explicit privacy error above. The endpoint may work for other public threads; further collection should be bounded, testable, and record native IDs and errors rather than treating it as a stable supported API.

Public script sources referenced by the sample page: [forums.js](https://community.akamai.steamstatic.com/public/javascript/forums.js) and [global.js](https://community.akamai.steamstatic.com/public/javascript/global.js). They are implementation evidence only, not API documentation. No session value or cookie was saved, transmitted, or included in this report.

## Access and evidence limits

- Official Web API docs distinguish public methods from protected methods; `GetAppReviews` and `GetNewsForApp` are anonymous/public. `IPublishedFileService/QueryFiles` requires an API key; the app client UGC API is not an anonymous server API.
- Public page probes do not establish a complete event-history guarantee. Steam may hide private, deleted, removed, or filtered content; absence on an index page is not a deletion signal.
- Anonymous tool failure is not treated as platform unavailability: public Steam Community HTML was fetched directly without cookies. Where the site-native body renderer explicitly returned a profile privacy error, that precise response is reported.
- All Steam Community comments beyond the review endpoint demonstrated by root remain a partial/undocumented capability. If archive coverage is required, use a cautious anonymous snapshot collector with stable native IDs, pagination checkpoints, raw-response preservation, and explicit per-endpoint errors; keep local snapshot import as a fallback and do not imply a complete supported API.
