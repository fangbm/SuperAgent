## 2026-11-04 Steam public feedback verification

An additional bounded anonymous probe verified the currently observed route shapes below. These are Steam Community site implementation, not documented Valve Web API methods. This corrects the earlier interpretation of one sample reply request: it omitted `extended_data`; with the topic page's `InitializeCommentThread` value supplied, the render route returned `success=true`, distinct reply pages, and an empty tail. An HTTP 200 with `success=false` is an error, never an empty page. No cookies, login session, or authentication were used.

## Native discussion endpoint evidence

The public topic page loads Steam’s current `forums.js` and `global.js`. The topic page calls `InitializeCommentThread("ForumTopic", "ForumTopic_{owner}_{forumGid}_{topicId}", …, "https://steamcommunity.com/comment/ForumTopic/", 40)`. Steam’s current public `global.js` constructs render paths as `base + "render/" + owner + "/" + feature + "/"`; page navigation uses `start = pageSize * page` and passes `feature2` (the topic ID), `totalcount`, and sort flags. A render request without `extended_data` returned the explicit privacy error; the public topic initialization provides this required parameter. With it, anonymous bounded requests returned successful distinct pages and an empty tail. These remain undocumented site details, not a stable supported API.

Public script sources referenced by the sample page: [forums.js](https://community.akamai.steamstatic.com/public/javascript/forums.js) and [global.js](https://community.akamai.steamstatic.com/public/javascript/global.js). They are implementation evidence only, not API documentation. No session value or cookie was saved, transmitted, or included in this report.

## Access and evidence limits

- Official Web API docs distinguish public methods from protected methods; `GetAppReviews` and `GetNewsForApp` are anonymous/public. `IPublishedFileService/QueryFiles` requires an API key; the app client UGC API is not an anonymous server API.
- Public page probes do not establish a complete event-history guarantee. Steam may hide private, deleted, removed, or filtered content; absence on an index page is not a deletion signal.
- Anonymous tool failure is not treated as platform unavailability: public Steam Community HTML was fetched directly without cookies. A site-native `success=false` response is an error, not an empty page; in the earlier sample, omitting required public `extended_data` caused the reported privacy error.
- Steam Community comment routes remain partial/undocumented capabilities. The public collectors use stable native IDs, Host checkpoints, bounded pagination and explicit endpoint failures; they do not infer deletion from missing objects or imply a complete supported API.
