## 真实 QQ 只读验收

发送前先进行无写入探针：intent 25 + 26（100663296）的 READY 会话已持久化，报告操作仍是 prepared / attempt 0。此历史证据只证明登录和订阅。

用户明确授权最多 4 条消息：一份固定报告和至多三条用户触发的只读回复。实际结果：

| 项目 | 结果 |
| --- | --- |
| 报告 | 同一预备操作只发送一次，09:15:34 获 accepted；用户确认收到。 |
| Bug 列表 | 用户私聊 /bugs 后获 accepted，随后从列表点击详情。 |
| 旧详情请求 | 已到达 Host，但旧代码把互动 UUID 用作 event_id，HTTP 400 明确拒绝，未计为成功消息。 |
| 两次详情 | 断线后恢复的两次独立点击均获 accepted，未收到客户端确认。 |
| ACK | 加入 X-Callback-AppID 后，实际返回 HTTP 200，三次耗时分别为 357、340、278 ms。 |
| 原文 | 未完成真实查询和客户端确认。 |

实际受理合计 4 条，另有一次明确拒绝的请求，网络消息发送尝试共 5 次。没有重发报告、没有 unknown 重放、没有 GitHub 或工作项状态修改。进程在额度用完时正常停止；剩余一条点击已取消并保留请求，避免以后补发。脱敏记录见 [m5-qq-live-2026-11-03.json](evidence/m5-qq-live-2026-11-03.json)。
