# Steam review comments connector — 2026-11-04

`SteamReviewCommentsConnector` is a separate `SourcePluginV1` exported from `@superagent/connector-steam-reviews`. Its manifest ID is `superagent.steam-review-comments`; its events keep platform `steam-reviews` so Core can bind it to the existing Steam source identity. The existing `SteamReviewsConnector` and its API are unchanged.

The adapter reads complete pages from the anonymous `GetAppReviews` endpoint to discover review IDs, owners, and reported comment counts. It polls only reviews with comments and previously known threads. Thread offsets and review pagination are committed through the SDK Host checkpoint; a one-request budget alternates metadata and thread work. Known threads, including zero-count threads, are revisited daily. Missing/private threads are not treated as deleted.

Checkpoint version 2 stores the app/source binding, cursors, thread scheduling and retry metadata, known review IDs, material fingerprints, revision counters, persisted event IDs, and observation times. It does not copy comment bodies or native HTML from the archive. `seedSteamReviewCommentsCheckpoint(config, previousCheckpoint, archivedEvents)` accepts a matching v1 anonymous-observation checkpoint (including its null cursor and array thread index) and the exact-bound archived comment projections supplied by Core; it seeds comment fingerprints/IDs and thread owners, and returns v2. Passing matching v2 is idempotent.

Rendered text retains line breaks and decoded text; normalized events also retain the native comment HTML fragment and endpoint metadata. The stable object ID is `comment:<recommendationId>:<commentId>` with parent review and thread links. Material fingerprints include the visible text and canonicalized `.commentthread_comment_text` HTML, so link/image-only changes are retained while surrounding UI controls do not create revisions. Native creation time remains the original event time. Comment edits have no exposed native timestamp, so changed snapshots use the persisted observation time and a revision counter; A→B→A remains three distinct events.

Coverage is reported as partial because anonymous current snapshots cannot recover deleted/private comments or intermediate edits between polls. Probe verifies an actual comment-render request when a public candidate exists and reports unknown when none is available. Private/malformed thread pages retain their offset and receive a per-thread retry time so other threads continue; they are reported as gaps, never deletions. HTTP errors, false-success payloads, malformed cursors/pages, and non-advancing pagination preserve the last committed cursor. A 429 retry deadline is checkpointed when retries exhaust the request budget. Requests are sequential, limited to 25 per sync including retries, paced at least two seconds apart, capped at 20 seconds and one megabyte, and do not use login state, cookies, or redirects.

Synthetic integration coverage is in `tests/integration/steam-review-comments.test.mjs` with fixtures under `tests/fixtures/m4/steam-review-comments*`. No live Steam request or canonical archive write was made in this work.
