## Fixed behavior

- One shared Gateway: public collector owns connection; forwards dispatches to private collector/community features. Interactions receive an immediate non-success processing/modal response; success follows archive commit. Advance Gateway sequence only after routed archives and durable entity intents commit. Preserve first receivedAt for partial/replayed dispatches; never persist interaction tokens.
- Public discovery includes public text/announcement/voice text and public active/archived threads; excludes staff/private/DM content. Private collector resolves only registered ticket channels. Both preserve source identity/history/checkpoints and report partial gaps.
- Private evidence uses project idle-abyss-princesses-private in the same SQLite file, sources permanently archive-only. Trusted ingress/admission/reprocess policy blocks downstream use even if normal workers are started. Public and private data never mix in a batch/context.
- Tickets: bilingual public panel; bug/suggestion/help modal; one open ticket/member; requester+bot+owner+manual Developer/Moderator only. Submission archived before confirmation/channel creation. Staff claim/close/reopen/add. Close read-only; manual deletion after final archival. Retain archive, no automatic purge. Unknown channel-creation outcomes require marker reconciliation, not blind retry.
- Rooms: lobby creates/moves creator to a four-place room, multiple parties, host name/capacity controls, oldest remaining occupant inherits ownership. Delete only bot-managed rooms after60seconds empty and final text-history flush. No audio recording.
- Community lifecycle work executes in a periodic tick outside the connector's serial dispatch hook, avoiding reentrant history-flush deadlocks. Gateway handlers persist intents; external work resumes from entity state. No separate task queue.
